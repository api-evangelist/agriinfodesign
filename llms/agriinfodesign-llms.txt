## The short version for an agent

Agri Info Design has a substantial, real, machine-readable API surface — 186 operations across four
contracts — and **no developer program whatsoever**. There is no developer portal, no API reference,
no getting-started guide, no authentication documentation, no SDK in any language, no CLI, no
sandbox, no status page, no changelog, no rate limits, no error catalogue and no documented way for
a third party to obtain a credential. The contracts are served publicly because springdoc and
Springfox serve them by default, not because the company published them for you.

## Identity and authorization (live documents)

- [Agricultural machinery OAuth scope catalogue](https://auth.agribus-connect.net/v1/agricultural-api/oauth/scopes)
  — ten `noki.*` scopes covering devices, locations, work records, environmental data and field

  have a published operation behind them.

## Domain standard

The datastore contract declares 農機オープンAPI v2.0.0 in its own tag metadata and implements the
device and location surface of the Japanese cross-vendor machine-data standard coordinated by NARO
under MAFF's agricultural data-infrastructure programme — `GET /v1/agricultural-machinery/devices`
and `GET /v1/agricultural-machinery/devices/{device_id}/locations`, the latter returning RFC 7946
GeoJSON. Since FY2022 MAFF has conditioned agricultural-machinery subsidies on manufacturers
providing open-API data linkage, which is the context this surface exists in.

## What an agent must know before calling anything

- **Auth:** `Authorization: Bearer <RS256 JWT>` issued by auth.agribus-connect.net. An
  unauthenticated call returns **403**, not 401, with no `WWW-Authenticate` header — and **500** on
  the pay service, which is a defect.
- **Errors:** no contract declares a single non-200 response across all 186 operations. Two vendor
  envelopes are used live: `{"code":"IAM-…","message":"…"}` and the Spring default
  `{"timestamp","status","error","path"}`. No RFC 9457.
- **Idempotency:** none. No `Idempotency-Key` anywhere, including on the money-moving billing writes.
- **Rate limits:** none published, and no `RateLimit-*`, `X-RateLimit-*` or `Retry-After` header is
  ever emitted.
- **Reversibility:** delete is the only undo, there is no undo for an edit, and no retention or
  refund window is stated anywhere — including on the Japanese commercial-transactions disclosure
  page where a Japanese seller would normally state a refund policy.
- **Deprecations:** 13 operations are flagged deprecated in the specs with no sunset date, no
  replacement pointer and no RFC 8594 headers on the live routes.
- **MCP / A2A:** neither. No MCP server and no agent card exist. Do not look for one.
