A new version 5.4.7 of the AgriBus-NAVI application has been released to the Google Play Store today. This version includes fixes for problems with data loading and the traveling reference line dialog, as well as the ability to change the camera direction in the guidance screen. We would like to ask all users of the application to please check it out.
